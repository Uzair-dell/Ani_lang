# 🌟 ANI-LANG

**A native cognitive language for AI communication**

Ani-lang is not a programming language. It is a **designed natural language** that serves as the primary communication medium for artificial intelligence—a medium the AI speaks natively, just as humans speak English, Urdu, or Arabic.

## 🧠 What Makes Ani-lang Different

Traditional AI systems communicate through human natural languages. This forces AI cognition into structures optimized for human social interaction, not for symbolic reasoning.

Ani-lang is designed **cognition‑first**:

- **Root‑based abstraction** (Arabic inspiration) – A single triliteral root generates an entire family of related concepts
- **Compound concept fusion** (German inspiration) – Multiple roots combine into a single word encoding a complex thought cluster
- **Contextual meaning** (Japanese inspiration) – A word’s interpretation shifts based on the AI’s goal, emotional state, and memory
- **Ontological hierarchy** (Sanskrit inspiration) – Every concept has a formal place in a layered abstraction tree

This combination creates a language that is **regular, unambiguous, expressive, and grounded in cognitive primitives**—not a human‑centric conlang, but a **semantic operating substrate for artificial minds**.

## 🚀 Current Status

**Phase 0 – Cognitive Primitives** is complete.  
The foundational layer is now defined:

- **Phonology** – 20 consonants, 3 vowels (each short/long), simple CVC syllables, stress on the first syllable.
- **Root primitives** – 25 triliteral roots covering core cognitive categories: change, curiosity, uncertainty, awareness, memory, desire, knowledge, intention, action, support, emotion, verification, recall, strategy, ability, pattern, time, space, hiddenness, error, growth, clarity, direction, learning, and method.
- **Ontology** – A hierarchical tree (Entity → Process, State, Drive, Faculty, Structure, Content, Relation, Quality, Property, Dimension) with leaf nodes for each primitive.

All Phase 0 files are validated and ready for the next step.

## 🔧 Setup & Validation (Phase 0)

1. **Install Python 3.11+** (if not already installed).  
   [python.org](https://python.org)

2. **Clone the repository**  
   ```bash
   git clone https://github.com/Uzair-dell/ani-lang.git
   cd ani-lang
   ```

3. **Run the validation script**  
   ```bash
   python check_phase0.py
   ```  
   Expected output:  
   ```
   ✓ phonology.json loaded OK
   ✓ roots.csv loaded OK – 25 roots found
   ✓ ontology.json loaded OK – 37 nodes

   Phase 0 files are valid!
   ```

If you see errors, verify that the file contents exactly match the versions in the repository.
